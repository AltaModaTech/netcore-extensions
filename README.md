This repo now uses [NuGet Trusted Publishing](https://learn.microsoft.com/en-us/nuget/nuget-org/trusted-publishing) for GitHub workflows. To publish all packages, push a new git tag.

'Publish-Release.ps1', the previous method used, has been removed.
